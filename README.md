# SchemeSathi

**Tagline:** *Will my application survive verification?*

SchemeSathi is a document-first eligibility and rejection-risk checker prototype for Indian student scholarships. It helps students spot blurry scans, cross-document name mismatches, missing documents, and rule mismatches before submitting on an official portal.

> **Data Handling Notice:** Documents are sent to an external LLM API for extraction. Use synthetic documents only.  
> **Threshold Notice:** Prototype. Confirm thresholds on the official portal. All scheme thresholds in `data/schemes.yaml` are marked `TODO_VERIFY` until verified against official portals.

---

## Core Principles

1. **AI reads, rules decide:** The LLM is used strictly to extract structured JSON fields (`full_name`, `annual_income`, `category`, `marks_percentage`, `course`, `issue_date`, `issuing_authority`) from document text. It never decides eligibility.
2. **Deterministic Python rules:** Eligibility thresholds, required documents, and certificate validity are evaluated deterministically in `core/rules.py` from `data/schemes.yaml`.
3. **No faked AI:** If the LLM call fails or API keys are missing, SchemeSathi displays the real error and lets the user enter fields manually.
4. **Honest method labels:** Every health check is explicitly tagged as `RULE`, `STRING SIMILARITY` (RapidFuzz `token_sort_ratio`), or `IMAGE TEST` (OpenCV Laplacian variance—classical image processing, not ML).

## Setup & Run Steps (Python / Streamlit)

1. **System requirement for OCR:** Install Tesseract OCR (`tesseract-ocr` on Debian/Ubuntu, `brew install tesseract` on macOS).
2. **Create a Python 3.11 virtual environment and install dependencies:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. **Configure environment variables:**
   ```bash
   cp .env.example .env
   # Add GEMINI_API_KEY (or GROQ_API_KEY with LLM_PROVIDER=groq)
   ```
4. **Generate synthetic sample & evaluation documents:**
   ```bash
   python scripts/make_samples.py
   ```
5. **Run the unit tests:**
   ```bash
   pytest -v
   ```
6. **Run the Streamlit app:**
   ```bash
   streamlit run app/streamlit_app.py
   ```
7. **Measure extraction accuracy on the synthetic eval set (requires configured LLM key):**
   ```bash
   python scripts/evaluate_extraction.py
   ```

## Limitations & What Is Real vs Planned

### What is real right now
- Real PDF text extraction via PyMuPDF and real OCR fallback via Tesseract.
- Real classical scan sharpness testing via OpenCV `cv2.Laplacian(...).var()`.
- Real cross-document name matching via RapidFuzz `token_sort_ratio`.
- Real structured JSON extraction via Gemini / Groq with Pydantic schema validation and 1 retry, plus manual entry fallback on failure.
- Real deterministic rule engine with boundary-tested operators (`<=`, `<`, `>=`, `>`, `==`, `!=`, `in`, `not_in`, `contains`) and downloadable Markdown/PDF reports.

### Limitations & Planned Work
- `data/schemes.yaml` contains 5 placeholder schemes with `TODO_VERIFY` thresholds until verified against official scholarship portals.
- Extraction evaluation metrics show `"Not yet measured"` until `scripts/evaluate_extraction.py` is executed with a valid API key.
- English strings are centralized in `core/strings.py`; Tamil and Hindi translations are planned.
- Out of scope: submitting applications, auto-filling official forms, or storing real student documents.
